# ChromaLab 🎨

Una utilidad de color ligera y sin dependencias diseñada para flujos de trabajo web rápidos. Convierte entre formatos de color modernos, valida el contraste WCAG y genera paletas armonizadas en tiempo real.

## Características

- **Conversión multi-formato:** Traducción instantánea entre HEX, RGB, HSL y el formato moderno OKLCH.
- **Accesibilidad WCAG 2.1:** Evaluación en tiempo real del ratio de contraste para legibilidad de texto (categorías AA / AAA).
- **Generador de Armonías:** Cálculo matemático para esquemas complementarios, análogos, triádicos y monocromáticos.
- **Controles HSL:** Ajustes interactivos para modificar el tono, la saturación y la luminosidad de forma fluida.
- **Copia rápida:** Copia cualquier código de color al portapapeles con un solo clic.
- **Cero dependencias:** Construido puramente con HTML, CSS y JavaScript nativo (*vanilla*).
