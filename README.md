# ChromaLab 🎨

A lightweight, dependency-free color utility designed for fast web workflows. Convert between modern color formats, validate WCAG contrast ratios, and generate harmonized palettes in real time.

## Features

- **Multi-Format Conversion:** Instant translation between HEX, RGB, HSL, and modern OKLCH formats.
- **WCAG 2.1 Accessibility:** Real-time contrast ratio evaluation for text legibility (AA / AAA ratings).
- **Harmony Generator:** Mathematical calculations for complementary, analogous, triadic, and monochromatic schemes.
- **HSL Controls:** Interactive sliders to smoothly adjust hue, saturation, and lightness.
- **Quick Copy:** Copy any color code to your clipboard with a single click.
- **Zero Dependencies:** Built purely with HTML, CSS, and vanilla JavaScript.

## 🚀 Quick Start

- 🌐 **Live App:** Access it directly at [adevohq.github.io/chromalab](https://adevohq.github.io/chromalab).
- 💾 **Local Usage:** No installation or build steps required. Simply download and open `index.html` in any web browser.
